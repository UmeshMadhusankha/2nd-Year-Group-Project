Frontend → Backend Flow:
  1. User selects filters in landing.php form
  2. JavaScript (landing.js) detects change via event listeners
  3. Calls filterProviders() which calls loadProviders()
  4. Builds URL with params: category, location, rating
  5. Fetches from: /get-providers (filtered) or /get-featured-providers (default)
  6. ProviderController receives params
  7. Passes to RepairerModel and CompanyModel with filters array
  8. Models use LIKE for district matching
  9. Results returned as JSON
  10. JavaScript renders provider cards
