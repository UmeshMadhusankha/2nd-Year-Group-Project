# Advertisement System - Quick Reference Guide

## 🚀 Quick Start

### Access the System
1. Login to company dashboard
2. Click "Advertisements" in sidebar (📢 icon)
3. View your advertisement dashboard

### Create Your First Ad
1. Click "Create New Advertisement" button
2. Follow the 5-step wizard:
   - Select ad type
   - Upload media & details
   - Set targeting
   - Schedule campaign
   - Review & pay

## 📅 Scheduling Options

### Option 1: Immediate
- Starts after moderator approval
- Typically 24-48 hours
- Best for urgent campaigns

### Option 2: Scheduled
- Set specific start date/time
- Set specific end date/time
- Perfect for seasonal offers
- Can be weeks/months in advance

## 🎨 Best Practices

### Images
✅ Use 1200x628px resolution
✅ Clear, bright, professional
✅ Minimal text overlay
✅ Show your service/product
❌ Pixelated or blurry
❌ Too much text
❌ Stock photos only

### Copy
✅ Clear value proposition
✅ Strong call-to-action
✅ Specific benefits
✅ Limited-time urgency
❌ All caps
❌ Too wordy
❌ Misleading claims

### Scheduling
✅ Plan seasonal campaigns
✅ Test different durations
✅ Check competitor activity
✅ Monitor budget pacing
❌ Too short (< 3 days)
❌ Overlapping similar ads
❌ Peak season only

## 📊 Metrics to Watch

**Primary Metrics:**
- **Views** - How many saw your ad
- **Clicks** - How many clicked
- **CTR** - Click-through rate (%)
- **Cost/View** - Efficiency metric

**Goals:**
- CTR > 2% = Good
- CTR > 5% = Excellent
- Cost per click < LKR 100 = Efficient

## 🔧 Common Actions

### Edit an Ad
1. Find ad in list
2. Click edit icon (✏️)
3. Modify details
4. Save changes
5. Resubmit if needed

### Pause an Ad
1. Find active ad
2. Click pause icon (⏸️)
3. Confirm action
4. Ad stops showing
5. Resume when ready

### Delete an Ad
1. Find ad in list
2. Click delete icon (🗑️)
3. Confirm deletion
4. Ad removed permanently

## 💡 Pro Tips

### Get More Views
1. Use priority placement
2. Target specific audience
3. Run during peak hours
4. Use compelling visuals
5. Update regularly

### Save Money
1. Start with 1-week test
2. Monitor performance daily
3. Pause underperforming ads
4. Use annual billing (save 20%)
5. Avoid priority if not needed

### Increase Clicks
1. Strong CTA button
2. Limited-time offers
3. Show clear benefits
4. Use action words
5. Test different copy

## 🚨 Troubleshooting

**Ad Rejected?**
- Check moderator feedback
- Review content policies
- Fix issues mentioned
- Resubmit for review

**Low Performance?**
- Change image/video
- Update copy
- Adjust targeting
- Try different schedule

**High Costs?**
- Reduce duration
- Remove priority placement
- Simplify to banner only
- Target more specific audience
